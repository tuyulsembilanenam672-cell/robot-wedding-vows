One line of wedding vows for a robot couple, entered in the make.fun bounty
"One-Line Robot Wedding Vows":

> I take you to be my lawfully wedded firmware, to have and to hold, through every update, until a factory reset do us part.

`main.ts` writes that single line (122 code points, within the 1–160 gate) to `/output/entry.txt`.
